# SimShieldAI

A recorded security-dashboard demo bringing camera controls, gun-detection alerts, and monitoring analytics into one interface.

**Project showcase · Recorded demonstration**

[Watch the demonstration](https://www.loom.com/share/c727ba1fe93048299086ba1e240700b0) · [Mason Vision portfolio](https://github.com/Mason-Adedortman/mason-vision-portfolio) · [Contact](mailto:adedortman2020@gmail.com)

## Problem

Camera activity and detection alerts need a clear operational view. The demonstrated product brings monitoring controls and alert review into a single command-center interface.

## Demonstrated approach

Cameras can be activated or deactivated from the dashboard. Gun-detection alerts include timestamps and confidence information, while monitoring analytics summarize activity.

## Output & scope

The 45-second product walkthrough focuses on the monitoring workflow: camera controls, alert review, and command-center analytics, presented together in a single dashboard.

## Demonstrated capabilities

Camera monitoring · Detection alerts · Dashboard analytics
